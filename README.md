# Ankit Das - Modern Developer Portfolio

This is a clean, responsive, and modern personal portfolio website built with HTML, CSS, and JavaScript. It showcases my technical skills, achievements, and educational background, and includes an interactive contact form integrated with EmailJS.

---

## Live Preview

🌐 [View Portfolio Online](https://your-github-username.github.io/your-repo-name/)

---

## 📌 Features

- ✅ Fully responsive design (mobile-first)
- ✅ Hero section with animated introduction
- ✅ Sections: About, Skills, Education, Achievements, Contact
- ✅ Smooth scroll and active nav highlighting
- ✅ Scroll animations using AOS (Animate On Scroll)
- ✅ Contact form with validation and EmailJS integration
- ✅ Modal-based feedback for form submission
- ✅ Scroll-to-top button
- ✅ Font Awesome icons and modern design

---

## 🛠️ Built With

- **HTML5**
- **CSS3**
- **Vanilla JavaScript**
- [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)
- [EmailJS](https://www.emailjs.com/)
- [Font Awesome](https://fontawesome.com/)
